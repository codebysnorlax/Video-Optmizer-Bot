# Spec Delta

## Purpose

Provides a flexible conversational AI video and audio engineering assistant capable of managing multi-asset sessions, executing complex compound FFmpeg transformations, and delivering multiple output files.

## ADDED Requirements

### Requirement: Multi-Asset Session Tracking
The system SHALL maintain an inventory of all media assets uploaded by the user during an active AI session, including file names, formats, codecs, and durations.

#### Scenario: User sends an additional audio track during an active session
- **WHEN** a user uploads a new audio file while an AI session is active for a previous video
- **THEN** the system registers the audio file alongside the original video and makes both assets available to the AI agent

### Requirement: Compound Multi-Output Execution
The system SHALL support executing compound operations that generate more than one output deliverable from one or more input assets within a single turn.

#### Scenario: User requests separate video and audio
- **WHEN** user requests separate audio and video files from a video
- **THEN** the system executes a dual-stream split producing a video-only file and an audio-only file in the sandboxed workplace

### Requirement: Stream Extraction and Muting
The system SHALL support isolating audio streams without video re-encoding and stripping audio tracks to produce muted video files.

#### Scenario: Audio extraction to MP3
- **WHEN** user instructs the AI to extract audio as MP3
- **THEN** the system executes FFmpeg with -vn and audio encoding, verifying the output file integrity before delivery

#### Scenario: Video muting
- **WHEN** user instructs the AI to mute a video
- **THEN** the system executes FFmpeg with -an and video stream copy, producing a muted video without generational loss

### Requirement: Audio Replacement and Multi-Input Remuxing
The system SHALL allow combining separate video and audio assets into a single synchronized media file.

#### Scenario: Replacing video soundtrack
- **WHEN** user specifies a video asset and an audio asset to replace the original soundtrack
- **THEN** the system maps the video stream from the first asset and audio stream from the second asset, outputting the combined file

### Requirement: Multi-Deliverable Telegram Upload
The system SHALL sequentially upload all deliverables generated by an AI operation to Telegram with live upload progress reporting for each file.

#### Scenario: Delivering multiple outputs
- **WHEN** an AI operation finishes generating two deliverable files
- **THEN** the system uploads both files into the Telegram chat with individual progress tracking and comparative analysis

### Requirement: Natural Language Problem Consultation
The system SHALL provide conversational guidance and technical diagnoses without requiring users to choose from fixed preset buttons.

#### Scenario: Freeform natural language query
- **WHEN** user sends any plain text question or instruction regarding video playback, size, or quality
- **THEN** the AI responds with actionable technical advice or offers an executable transcode plan
