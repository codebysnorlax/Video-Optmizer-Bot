# Proposal

## Why

The current AI Manual mode restricts users to single-file inputs and single-output transcoding plans, creating the perception of an inflexible "4-command" preset menu rather than an intelligent media engineering assistant. Users frequently need compound operations—such as splitting a video into separate video-only and audio MP3 deliverables, or sending an external audio file to replace an existing video's soundtrack—without being artificially constrained by single-file or rigid tool schemas.

## What Changes

- **Multi-Asset Session Tracking**: Enable active AI sessions to index multiple files (video, audio tracks, clips) uploaded by the user in the conversation session, allowing operations that combine or switch audio/video sources.
- **Compound & Multi-Output Safe Execution**: Upgrade the AI tool execution engine to handle multi-command pipelines and multi-output operations (e.g. producing both `video_mute.mp4` and `extracted_audio.mp3` in one turn).
- **Expanded Media Operation Capabilities**: Empower the LLM with safe FFmpeg stream mapping (`-map`), track stripping (`-vn`, `-an`), audio replacement, clipping, speed adjustment, volume boost, and format transcoding.
- **Multi-File Delivery Pipeline**: Update Telegram delivery logic to sequentially probe, upload, and format comparison summaries for all output deliverables generated by a plan.
- **Open Conversational Interface**: Reframe the AI interaction flow from button-dominated presets to an open natural language consultation experience.
- **Bug Fixes**: Resolve `record_task_complete` missing argument (`elapsed_time`) and callback query event attribute errors (`event.message` -> `event.get_message()`).

## Capabilities

### New Capabilities
- `conversational-ai-assistant`: Freeform natural language media engineering, multi-asset session awareness (audio + video), multi-operation tool execution, and multi-file artifact delivery.

*(None - first specification of this capability)*

## Impact

- `core/ai/tools.py`: Update tool schemas to support multi-input and multi-output specifications with strict sandbox validation.
- `core/ai/agent.py`: Enhance system instructions and prompt context with multi-asset metadata.
- `bot/ai_handler.py`: Support multi-file delivery, session asset accumulation, and conversational routing.
- `bot/callbacks.py`: Fix callback message handling and cleanup flow.
- `tests/test_ai_agent.py`: Add test cases for multi-input remux, audio extraction, and multi-output deliveries.
